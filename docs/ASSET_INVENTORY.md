## M5 运行资产
M5 将三份处理版 GLB 派生为 assets/runtime 下的同名 GLB。资产映射与生产构建使用这三个文件。Meshoptimizer 以保留 UV、法线、轴向极值及车辆轮底接触顶点为约束生成简化索引，同时压紧顶点缓冲。原始处理版仍在 assets/processed/blender。重建命令为 node scripts/build-render-models.mjs；该离线步骤使用项目内的 meshoptimizer 及 Python/Pillow。日常启动和构建直接使用现有运行资产。
