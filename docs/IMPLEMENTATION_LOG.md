## M4 · 2026-11-18
右侧新增 300 px 深紫半透明控制面板（src/ControlPanel.tsx），整合视觉预设、四种镜头、列车控制、光影、可折叠云海和显示选项。760 px 及以下宽度默认收起，展开后作为底部抽屉；桌面与手机分别给右边和下方预留取景空间。面板独立于 Canvas，轨道环绕监听仍只绑定 Canvas。收起面板、隐藏/显示整个界面及键盘 Escape 均有对应入口。

src/config/scenePresets.ts 定义三套色板及各自的云量、云影、柔和度、日照、雾强、饱和度。src/scene/Palette.tsx 为天空、云、雾与 GLB 灯光插值颜色，切换窗口 0.9 秒。云海各层与云底使用实际色板 uniform。饱和度由三维视口单独调节。现有全景含固定云层，继续使用渐变天空。景深尚未接入后处理，工程无音频素材，相关控件灰显并标明原因。

| 操作 | 效果 |
|---|---|
| 切换预设 | 应用新色板和配套视觉值；保留列车进度、速度、镜头及云海播放状态 |
| 重置当前预设 | 恢复该预设的视觉值及云海初始设置（含层数、种子、质量、显隐与动画）；保留列车和镜头 |
| 恢复珊瑚晚霞初始状态 | 恢复默认画面、远景、车速 4，并回到起点发车 |
| 回到起点 | 当前预设和镜头保持，列车回到出发点并暂停 |

Zustand 统一管理设置。项目使用 localStorage 键 cloudline-express-settings 和版本 4，仅保留可恢复的配置；进度、到站状态和调试状态独立。旧 pointcloud/hybrid 或未经验证的 panorama 缓存迁移为 gradient，重新写入时清理旧枚举。读取时校验数值、种子、枚举与范围。

npm test（5 文件 26 项通过）与 npm run build（含类型检查）通过。新增 tests/preset-settings.test.ts 覆盖三套预设、重置语义、旧缓存迁移和异常输入。主脚本 gzip 约 339 kB，Vite 仍提示单块超过 500 kB，设备性能留待 M5 实测。

生产预览在 Edge 软件 WebGL 的 1366×850 与 390×844 窗口验证。通过界面依次切换橘色暮光、紫夜航线，检查选中状态与日照/饱和度；手动调整后分别执行当前预设重置和全局恢复；验证列车再次发车、隐藏界面、设置刷新恢复、旧 hybrid 缓存迁移。切换及重置期间三个模型合计三次请求，均为 HTTP 200。移动抽屉中可选镜头、调节远景层数与收起面板。截图位于 docs/verification/m4，包括 coral、orange、violet、mobile-open、mobile-closed。窄屏验证使用桌面浏览器视口模拟。
