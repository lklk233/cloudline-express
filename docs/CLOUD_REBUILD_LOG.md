# M2 三层程序化云海
2026-11-18。启动 npm run dev 后打开首页。右上角“云海 / CLOUDS”调节参数；窄屏时面板位于右下方。开发服务保留 M1 场景校准，并增加“侧看云团”观察角度。

## 层次与控制

| 层次 | 空间与绘制 | 参数 |
|---|---|---|
| A 远景 | 以轨道中点为中心的多圈圆柱内壁，每组有独立半径、高程和噪声相位。在世界 XZ 坐标上绘制连续云带、明暗色带和柔化边缘。 | 默认 5 组，可选 2–8。云量改变覆盖范围，云速和风向控制漂移，层间漂移倍率不同。 |
| B 中景 | 每簇由 10 个变形云瓣组成，复用同一几何和材质，批量实例化。起伏的底层网格衔接桥下云簇，按日照和云影调整色阶。 | 默认云量 0.65 时，高档 65 簇、低档 35 簇。缩放改变云瓣与簇的尺度。高低档同时改变几何细分。 |
| C 近景 | 位于桥墩周围的半透明雾片。世界空间摆放，低频噪声漂移，关闭深度写入，软化四周边缘。 | 高档 10 片、低档 5 片。雾强为 0 时消失。薄雾速度独立于 A/B 云速。 |

设置统一由 Zustand 管理。默认布局种子 20261118；输入安全整数后回车或移开焦点生效。云层显隐同时作用于 A/B/C；动画使用累计时钟，暂停后保持原相位。未改变已有桥梁、车头、车厢的加载地址和标定。默认场景使用程序化渐变天空。

## 轨道安全通道

从 M1 两个轨道端点求中点、切向和横向，取轨顶高程 0.24。列车最大半宽 1.49，向外留出 2 个模型单位。检查覆盖整个云瓣包围范围，并计入水平漂移余量。可能进入通道的中景云瓣顶端限制在轨顶以下 2 个模型单位。镜头侧云团和雾片另有限高，以保留车轮视线。底层网格在最高云位仍保留起伏。

自动测试以三个布局种子、最大云团尺度 2、最高云位 +20 和水平漂移极值组合检查通道。另在浏览器将云量设为 1、尺度设为 2、高度设为 +20，检查默认远景下车头和两节车厢的轮廓。
