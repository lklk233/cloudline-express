# M5 画面、帧率与稳定性
2026-11-18。在同一台 Windows 机器上，M4 与 M5 的默认远景均达到约 60 FPS。M5 在 1080p 高档将单帧三角形提交量降至原来的约 18.5%，并将三份运行 GLB 的合计体积从 51.96 MB 降至 7.30 MB。

## 实测条件

- Windows 10.0.26200，Intel Core i9-14900HX，NVIDIA GeForce RTX 4060 Laptop GPU，Edge 157.0.4341.60。通过实际 WebGL 上下文确认 ANGLE / D3D11 硬件后端。
- 两轮均使用生产预览、同一浏览器启动参数。每组从新页面启动，使用默认珊瑚晚霞、远景、种子 20261118、5 层远云、云量 0.65、车速 4，列车和云海同时运行。
- 模型就绪后预热 6 秒，再采样约 12 秒。记录 Three.js 每次完成 render 调用的时间戳。平均 FPS 按帧间隔数除以总时间计算，P95 为帧间隔的第 95 百分位。三角形数及 draw call 数取样本末帧；各组末帧列车进度均约为 49%。这是应用渲染提交节奏，屏幕实际呈现与 GPU 单帧耗时未独立测量。

| 1920×1080，高 | 1920×1080 → 1920×1080 | 60.0 → 60.0 | 17.4 → 17.5 ms | 2,655,192 → 491,564 | 29 → 28 |

桌面实测达到计划书的 45 FPS 基本目标与约 60 FPS 目标。三个配置均在约 60 FPS 附近，主要收益体现为更低的绘制量、像素开销及资源体积。移动视口使用同一 RTX 4060，手机真机上的 30 FPS 目标仍待测。

## 画面校准和画质策略

- 依据计划书的美术构图、已有云海全景配色与 M4 同机画面对照，缩短蓝天至夕照的过渡区，增加远景云带的阴影层次。中景云瓣沿变形表面计算连续法线，保留高档近景轮廓。仓库内未找到单独的主视觉概念图文件。
- 桥段使用派生网格，稍提亮桥体和钢轨受光色；列车按原纹理中的侧窗位置、色相与高度对玻璃添加渐变暖光。车漆、轮底、车厢间隙与运行路径沿用原标定。模型详情见 [资产清单](ASSET_INVENTORY.md)。
- 默认云量下，高/低档中景分别绘制 650/350 个云瓣；低档减少几何细分、噪声采样与云底网格。桌面高/低档为 9/4 片薄雾，窄屏为 6/3 片。两个档位均有独立的远景云组、中景几何与近景雾片。
- 新窄屏会话默认低档，已有明确画质选择优先。桌面高/低档 DPR 上限为 1.5/0.9，窄屏为 1.3/1。以连续帧的平均间隔决定降档与恢复，间隔高于 31 ms 时降低 DPR，低于 18 ms 时逐步恢复，调整之间至少间隔 3.5 秒。只改变画布内部尺寸，HTML 标题、滑块和抽屉保持原分辨率。

## 稳定性验证

1. 连续 12 轮执行低档 → 橘色暮光 → 紫夜航线 → 高档 → 珊瑚晚霞。每轮回到相同视角后读取资源计数。稳定状态为 18 个几何体、6 张纹理、9 个程序、73 个 WebGL 活动缓冲区，回到原场景后未出现递增。此记录覆盖计数与观察时段，驱动的显存字节数未单独采集。
2. 依次调整窗口至 1920×1080、760×720、390×844、844×390、1280×800。逐项检查相机纵横比、内部绘制尺寸、有限的镜头坐标、上下文和页面横向溢出。
3. 执行 5 轮发车、暂停列车、播放云海、暂停云海。云海单独播放时列车进度保持原值。两者暂停且镜头稳定后，350 ms 观察窗内额外场景帧数为 0。仅使用已验证的渐变天空，全景入口沿用 M4 的禁用状态。
4. 三份运行 GLB 均仅请求一次，HTTP 200。预设和质量切换没有再次下载模型，浏览器控制台与页面异常为零，上下文丢失为零。

5. 单独施加每帧 40 ms 的测试负载，高档 DPR 从 1 降至 0.85，解除负载后恢复至 1。该段单独运行，表中的 FPS 采样未施加测试负载。

## 复测入口

先运行 `npm test` 与 `npm run build`。本轮 6 个测试文件、28 项测试及类型检查和构建通过。主 JS gzip 约 340 kB；Vite 仍给出主块大于 500 kB 的提示。

`node scripts/measure-m5.mjs after` 运行三个性能场景，`node scripts/check-m5-stability.mjs` 运行切换和启停检查。需要可用的本地 Edge 和 Playwright。脚本支持通过 `EDGE_PATH` 指定浏览器、通过 `PLAYWRIGHT_MODULE` 指定已有的 Playwright 入口。基线数据在更换 M4 运行资产前采集。
