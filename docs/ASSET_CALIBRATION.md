# M1 外景资产标定

采用 assets/processed/blender 中的三份外景 GLB。Y 向上，线路沿 +X，桥中线为 Z=0。网格侧投影显示车头驾驶室居后，流线形车首朝 +X。模型旋转为零，统一保留原始尺寸。场景尺寸均以模型单位计。

| 项目 | 测量与放置 |
|---|---|
| 桥面 | 读取 GLB 的 POSITION 数据，按横向位置采样中央 22 单位长的区段。桥中央至约半宽 1.3 处的上表面接近 Y=0，较高凸起分布在边缘。七段各长 25，以 X=-75 至 +75 间隔 25 放置。 |
| 轨道 | 沿平坦中央桥面铺轨枕和两根钢轨。左右轨心 Z=±1.10，单轨宽 0.14，枕顶 Y=0.10，轨顶 Y=0.24。中心线路径从 (-87.5,0.24,0) 至 (87.5,0.24,0)。轨心距按模型轮底选取。 |
| 轮底 | 取两条轨头宽度范围内的最低顶点。车头负 Z 侧约 0.0078、正 Z 侧约 0.0034，车厢分别约 0 和 0.0042。车头接触基准取 0.005，车厢取 0.002。模型整体放置高度等于轨顶减去各自基准。 |
| 编组 | 一车头两车厢，头车中心 X=20。各车辆间距按相邻包围盒半长之和加 0.18 计算。车厢与桥段共享已加载的几何、材质及纹理。 |
| 精度 | 自动测试核验各车左右接触带最低点与轨顶的绝对差均小于 0.006。该指标针对整车两侧接触带；各个车轮的生成网格形状略有差异。 |

默认远景截图与开发校准近景位于 verification/m1。运行 npm run dev，展开右下角“场景校准”可切换近景、显示坐标轴/包围盒或独立隐藏三个模型类别。轨道随桥梁显隐。近景用于开发检查。

默认天空由着色器按观察方向生成，水平夕照过渡至上方蓝色与下方紫色。检查现有全景缩略图后可见地平线以外已有大面积固定云海，暂保留素材归档，M1 只启用渐变天空。

## M3 列车运行区间
沿 M1 中心线用累计弧长定位。起点取 X=-87.5，行进方向为 +X，总长 175。车头中心至两节车厢中心的弧长差分别为 10.83、21.81，轮底偏移继续使用 M1 的标定值。为使两端都有停车余量，首尾各保留 1 个模型单位。发车时车头中心在 X=-59.29，终点停在 X=81.25；车头中心的有效行程为 140.54。开发用轮轨近景随车头位置更新。
